# Предрелизная версия v4 — 2026-09-08

Реализовано по ТЗ v4 владельца: подтверждённый тон документов и инженерии, шесть юридических фактов, отдельный следующий этап по воде, точный пакет материалов, десять FAQ, финальный контакт и переходы между разделами.

Структура: Hero → состав → схема → аэрофото → юридическая готовность → инженерия → материалы → визуализации → экономика → локация → реальные фото → FAQ → контакт.

Подключена предоставленная схема v4 с подписью «71 участок», сжата в WebP. Исходник: Материалы для сайта/01_Схемы_генплан_кадастр/5.2-Га-схема-сайт-v4.png.

Вёрстка: компактные функциональные заголовки, секции 52 px на мобильных и 64–80 px на desktop, выровненные CTA, тёплый блок материалов, тёмные переходы к документам. Плавающий контакт скрыт рядом с контактными действиями и меняет назначение возле локации.

Проверено production-сборкой и браузером Chromium: ширины 390, 768, 1366, 1440 и 1920 px; порядок секций, отсутствие горизонтального скролла и битых изображений; окно связи и текст сообщения; увеличение схемы; переключение галереи; FAQ. Ошибок в сценарии и консоли не обнаружено.

Встроенные проверки SEO, страницы, внешних ссылок, мобильных правил и отсутствия форм проходят. Все 10 фотографий и 15 визуализаций сохранены.

Команда браузерной проверки: node scripts/review-prerelease.cjs. PLAYWRIGHT_PACKAGE указывает на установленный Playwright, REVIEW_URL — на запущенную preview-сборку. Снимки сохраняются в исключённую из Git папку .audit_tmp.
