# Сборка и выпуск

Статический Vite-сайт, без базы, API, админки и контактных форм.

## Окружение

Переменные задаются в окружении сборки (CI, Docker build args или PowerShell `$env:...`). Генератор не читает `.env.local` автоматически.

- `SITE_URL` — настоящий HTTPS origin без пути. Обязателен для `pnpm run build`.
- `SITE_INDEXABLE=true` — только для публичного релиза. По умолчанию false/noindex.
- `VITE_METRIKA_ID` — настоящий ID, иначе оставить пустым.
- `ALLOW_LOCAL_PRODUCTION_PREVIEW=true` — только для локального HTTP-теста; не включать на релизе.

Проверки: `pnpm run build`, `check:seo`, `check:page`, `check:mobile-safety`, `check:runtime-contracts`, `check:external-links`.
Для разработки: `pnpm run dev`. Для готовой сборки: `pnpm run preview`.
На хостинг копируется содержимое dist, не исходники/материалы/.env. Изображения больших размеров нужны для просмотра крупно и не должны удаляться вручную.

## Цели Яндекс Метрики

Добавить JavaScript-цели: `click_phone_call`, `lead_telegram_click`, `lead_whatsapp_click`, `lead_hero_memo`, `lead_due_diligence`, `lead_cadastre_registry`, `lead_fin_model`, `lead_site_visit`.
Дополнительные: `materials_request`, `masterplan_open`, `gallery_open`, `route_open`, `map_open`, `section_view`, `hero_view`, `scroll_depth`, `contact_click`.

`lead_fin_model` означает запрос исходных данных, не скачивание файла. Любой click — это намерение связаться, не подтверждённый лид или состоявшийся звонок. Не использовать названия, обещающие отправку формы. После подключения проверить реальные события с согласием и отсутствие загрузки Метрики при отказе.

Для UTM используйте короткие campaign-коды: латиница, цифры, `_`, `-`, до 80 символов, либо числовой ID до 9 знаков. Свободный текст/контакты в URL не допускаются. Неизвестные параметры и значения отбрасываются. Черновик мессенджера может содержать разрешённые коды; сайт не отправляет сообщение сам.

## Возврат версии и автоматизация

Перед выпуском ставьте отдельный Git-тег и сохраняйте артефакт dist с SHA коммита. Исходники в Git — не замена резервной копии настроек хостинга. Для отката используйте предыдущий артефакт или новый revert-коммит, без переписывания истории.

CI проверяет сборку на main и pull request. Автодеплой не подключён к неизвестному серверу: после выбора хостинга добавить защищённое environment production, необходимые secrets и выкладку проверенного артефакта. Production build использует реальный SITE_URL и SITE_INDEXABLE=true. Старый review-репозиторий и настройки Sites не являются релизным контуром.
