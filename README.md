# «Новое Бородино» — лендинг земельного актива 6,2 га

Текущая версия сайта посвящена одному предложению: единому земельному массиву
площадью 6,2 га в Можайском районе: 71 участок под застройку и 1 га внутренних дорог.

На публичной части сайта нет каталога отдельных участков, предложений домов,
других лотов, форм заявок и CRM. Посетитель может изучить схему, реальные
фотографии и визуализации концепции, затем связаться с Екатериной Хабаровой по
телефону или в мессенджерах.

Предыдущая контактная версия сохранена в Git-теге
`archive-contact-site-2026-08-31` и архиве проекта.

## Контакты

Контактные ссылки находятся в [src/data/contacts.js](src/data/contacts.js).
После их изменения сайт необходимо пересобрать.

## Перед публикацией

Укажите настоящий HTTPS-домен в `SITE_URL`, соберите проект и выполните
проверки:

```powershell
pnpm run build
pnpm run check:seo
pnpm run check:external-links
pnpm run check:mobile-safety
pnpm run check:runtime-contracts
```

Яндекс Метрика отключена до создания нового счётчика для настоящего домена.
После указания `VITE_METRIKA_ID` она будет загружаться только после согласия
посетителя на аналитические cookie.
